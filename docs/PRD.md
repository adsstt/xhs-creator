# 小红书图文创作与运营助手 PRD

## Problem Statement

个人小红书创作者在日常内容生产中，需要持续完成选题发散、标题构思、正文撰写、标签整理、封面字提炼、配图顺序规划、发布前检查和发布后数据复盘。这些工作往往分散在文档、相册、表格、AI 对话工具和手动计算中，流程割裂，重复劳动多，也很难把历史数据及时反馈到下一次创作。

用户面对的核心问题包括：

- 创作启动成本高：有主题或图片素材，但不知道如何组织成可发布的图文内容。
- 版本比较困难：缺少 A/B 方案，标题、正文和封面表达通常只能凭感觉选择。
- 配图与文案脱节：图片素材、封面字、配图顺序和修图建议没有形成完整发布包。
- 生图链路不清晰：用户既希望有免费方案，也希望在需要时使用付费 API 自动生成图片。
- 运营复盘轻量但琐碎：曝光、点赞、收藏、评论等数据容易散落，互动率和内容方向表现需要手动整理。
- 从复盘到优化缺少闭环：数据看到了，但下一轮选题、标题和内容结构如何调整不够明确。

因此，产品需要提供一个面向个人创作者的轻量工作区，将“小红书图文创作”和“运营数据复盘”放在同一条闭环里，帮助用户更快完成可编辑、可发布、可复盘的内容方案。

## Solution

小红书图文创作与运营助手是一个面向个人博主的图文创作和轻量运营复盘工具。用户可以输入主题、问题或图片描述，也可以上传 1-9 张图片素材，系统生成两套 A/B 图文发布包，包含标题备选、正文、标签、封面字、配图顺序建议、修图/风格化建议和发布检查清单。

产品同时提供可选的主题生图能力。系统会基于用户主题和生成的发布包生成一段可编辑的生图提示词，用户可以选择 ChatGPT 网页版免费手动生成，也可以使用 OpenAI API 或阿里万相进行付费自动生成。

运营侧提供轻量数据看板。用户可以手动录入笔记数据，也可以通过 CSV 批量导入历史数据。系统自动计算笔记数、曝光、点赞、收藏、互动率、内容方向表现和近期数据，并给出复盘建议，帮助用户把表现好的内容方向、标题结构和互动策略复用到下一轮创作。

产品的核心闭环是：

1. 输入主题或上传素材。
2. 生成 A/B 发布包。
3. 可选生成或编辑主题生图提示词。
4. 复制、下载并发布内容。
5. 录入或导入运营数据。
6. 查看数据看板和复盘建议。
7. 将复盘结论用于下一轮创作。

## User Stories

1. As a 个人小红书博主, I want to 输入一个主题或问题, so that 我可以快速开始一篇图文笔记的创作。
2. As a 个人小红书博主, I want to 上传 1-9 张参考图片, so that 系统可以根据素材数量和上下文给我配图建议。
3. As a 个人小红书博主, I want to 删除已经上传的单张图片, so that 我可以在生成前清理不合适的素材。
4. As a 个人小红书博主, I want to 只输入主题而不上传图片, so that 没有图片素材时也能先生成文案方案。
5. As a 个人小红书博主, I want to 选择内容方向, so that 输出内容更贴合穿搭、美妆、旅行、美食、健身、职场、情感、家居等场景。
6. As a 个人小红书博主, I want to 输入自定义内容方向, so that 小众选题也能得到匹配的表达。
7. As a 个人小红书博主, I want to 一次生成 A/B 两套发布包, so that 我可以比较不同标题、正文和封面表达。
8. As a 个人小红书博主, I want to 每套发布包包含多个标题备选, so that 我可以挑选更适合发布的标题。
9. As a 个人小红书博主, I want to 每套发布包包含正文, so that 我可以直接编辑后发布。
10. As a 个人小红书博主, I want to 每套发布包包含标签建议, so that 我可以减少手动搜索和整理标签的时间。

13. As a 个人小红书博主, I want to 获得修图或风格化建议, so that 图片视觉和文案风格更统一。

## Implementation Decisions

- 产品定位为单人创作者使用的轻量 Web 工具，优先服务个人内容创作和复盘闭环。
- 产品信息架构分为首页、创作发布包工作区、运营数据复盘工作区和设置面板。
- 首页承担产品入口职责，使用轻量 poster 先占位，再加载背景视频，降低首次进入时的等待感。
- 创作发布包工作区采用素材、文案、图片三步流程，帮助用户理解从素材输入到发布包生成再到主题生图的顺序。
- 素材区支持 1-9 张图片上传、预览和单张删除；图片作为用户创作上下文和配图建议参考。
- 主题区支持主题、问题或图片描述输入，同时提供常见内容方向和自定义方向。
- 文案生成使用结构化 prompt 约束输出，使 A/B 发布包稳定包含标题备选、正文、标签、封面字、配图顺序、修图建议和发布检查清单。
- 发布包解析应优先输出结构化结果；当解析失败时，仍应保留模型原始文本，保证用户不会丢失生成内容。
- 主题生图为可选能力，默认由用户在设置中启用。
- 生图提示词由用户主题和第一套发布包信息生成，生成后必须允许用户继续编辑。
- 生图方式采用 Free-first + Paid fallback：ChatGPT 网页版免费手动生成、OpenAI API 付费自动生成、阿里万相付费备用生成。
- ChatGPT 网页版方式只负责复制提示词并打开网页，不自动代替用户在第三方页面执行操作。
- OpenAI API 和阿里万相方式由用户明确点击后触发，不自动串联 fallback，避免不透明计费。
- 图片生成失败时展示错误原因，不静默切换 provider。
- 设置面板集中管理 DeepSeek、OpenAI 和阿里万相相关配置。
- API Key 优先使用页面输入，其次可使用环境变量；页面输入的 Key 保存在浏览器本地。
- API Key 输入确认使用轻量提示，避免打断用户配置流程。
- 运营数据支持手动录入和 CSV 批量导入两种方式。
- 手动录入表单以“标题、内容方向、指标、日期、保存”为主操作流，减少左右留白和纵向堆叠。
- CSV 导入区域独立呈现为批量导入模块，支持下载模板、点击导入和拖拽导入。
- CSV 解析支持英文列名和中文列名，降低用户整理表格成本。
- 运营看板基于本地记录实时计算，展示总体指标、趋势、方向表现和近期数据。
- 指标趋势使用点折线展示，不使用面积填充，避免视觉上误读数据量。
- 近期数据支持按条删除，并提供二次确认以防误触。
- 复盘建议基于当前数据自动生成，重点覆盖最佳内容方向、高价值笔记和下一轮优化动作。
- 产品不自动发布内容到小红书，不绕过平台登录、风控或访问限制。
- 当前上传图片主要用于素材预览和上下文提示，不承诺真实多图视觉理解。

## Testing Decisions

测试应重点覆盖用户可观察行为和关键业务规则，避免测试模型内部的非确定性生成细节。对于 AI 输出，测试关注“结构完整性、失败降级、用户可继续操作”，而不是固定文案逐字匹配。

需要测试的模块和行为包括：

- 内容生成模块：输入主题后能够构建包含产品角色、输出结构、质量要求和用户上下文的 prompt。
- 发布包解析模块：能够解析标准 A/B 发布包；解析失败时保留原始文本用于复制和下载。
- 素材上传模块：能够上传多张图片、展示全部预览、删除任意单张图片，并在删空后恢复初始状态。
- 主题生图提示词模块：能够基于主题和发布包生成提示词，并允许用户编辑后用于复制和生图调用。
- 生图 provider 模块：用户选择 OpenAI 时只调用 OpenAI；用户选择阿里万相时只调用阿里万相；失败时展示错误。
- ChatGPT 网页版入口：点击后复制当前编辑后的提示词并打开 ChatGPT 页面。
- 设置模块：API Key 输入后保存到本地配置，并在 Enter 或失焦后展示轻量确认提示。
- 运营数据录入模块：手动新增数据后看板指标自动刷新。
- CSV 导入模块：中文列名和英文列名均能导入为统一记录结构。
- 运营计算模块：正确计算笔记数、总曝光、总点赞、总收藏、评论和互动率。
- 趋势展示模块：指标卡片使用折线和节点表达近期变化。
- 近期数据模块：二次确认后才能删除记录，删除后看板和复盘建议同步更新。
- 复盘建议模块：空数据时给出录入引导；有数据时输出最佳方向、高价值笔记和下一步优化建议。
- 首页加载模块：poster 能先于视频显示，视频可播放后平滑接管背景。

验收标准：

- 用户输入“春日咖啡店探店”并上传 3 张图片后，系统能生成至少 2 套发布包；每套发布包至少包含 3 个标题备选、正文、标签、封面字、配图顺序建议、修图建议和发布检查清单。
- 未配置 DeepSeek API Key 时，用户能看到明确提示，无法误以为系统正在生成。
- 启用主题生图后，系统能生成可编辑的生图提示词，并展示三种生成方式。
- 用户编辑生图提示词后，ChatGPT 复制入口和付费 API 生成均使用编辑后的内容。
- 用户手动录入一条笔记数据后，总笔记数和相关指标立即更新。
- 用户导入包含中文列名的 CSV 后，近期数据表能展示导入记录。
- 用户删除近期数据时，第一次点击只进入确认状态，第二次点击才删除。
- 空运营数据状态下，复盘建议区域给出清晰引导，不出现报错或空白。

## Out of Scope

- 不自动发布内容到小红书。
- 不自动抓取小红书后台数据。
- 不绕过小红书登录、风控、访问限制或平台规则。
- 不提供多账号管理、团队协作、客户审核流或商业投放管理。
- 不提供电商转化归因、广告 ROI 分析或复杂 BI 报表。
- 不承诺真实识别上传图片中的具体物体、人物、文字或构图细节。
- 不自动代替用户在 ChatGPT 网页或其他第三方页面完成生图操作。
- 不保证 AI 生成内容可以不经编辑直接发布，用户仍需进行事实、合规和风格检查。

## Further Notes

- 产品优先服务个人博主的高频轻量工作流，核心价值是“更快形成可编辑发布包，并能用数据推动下一轮创作”。
- 内容输出应保持自然、真实、适合个人分享，避免过度营销腔、虚假承诺和平台违规表达。
- 生图功能应持续明确免费方式和付费 API 的差异，避免用户误触付费调用。
- API Key 和敏感配置应尽量减少暴露面，页面提示要清楚说明保存位置和使用优先级。
- 后续可以扩展真实多模态图片理解、多版本封面图生成、选题库、发布日历、Excel 导入、长期趋势分析和合规授权下的数据自动同步。
